Privacy

Dododo Local Publisher is operated by the owner of the Dododo clip channels. It is a private application running on that operator's Windows computer. It uses YouTube API Services.

Information used

The application reads the authorized channel ID and name, and the status, metadata, processing information and thumbnail of videos it uploads. It reads the operator's approved video files, thumbnails and publication settings. It does not request passwords, phone verification codes, browser cookies, viewer profiles or analytics data.

Purpose and storage

This information is used to send a reviewed upload to the correct channel, prevent duplicate uploads, apply its thumbnail and publication settings, and confirm the resulting state. OAuth credentials and resumable upload addresses are encrypted using Windows protection for the current Windows user. Upload records and review evidence are stored locally. No application server receives a copy.

API responses and downloaded thumbnail copies are temporary verification data. They must be refreshed or removed within 30 days. Removing these API copies does not delete the operator's original videos or thumbnails. The application is intended for the operator's own use; it does not accept data from other channel owners.

Sharing

The selected files and publication settings are sent to Google/YouTube over HTTPS. The program does not sell data, serve advertising or send API credentials to an AI model. When the operator asks an assistant to review local status or images, that material may be processed by the assistant service under that service's own terms. Credentials are excluded from that review.

This documentation site is hosted by GitHub Pages. Its hosting service may receive ordinary connection information. The local application does not add advertising cookies or analytics trackers. Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting local data

The operator can revoke the application's permission at any time through Google's account permissions page. The program will then require a new authorization. Local OAuth credentials are stored under %LOCALAPPDATA%\DododoLocalPublisher. API verification files are stored in the project's operations/evidence/youtube_api directory; API journal entries are in its local SQLite database.

To stop using the application, revoke access, stop its worker and remove its locally stored credentials and API copies. Questions or data-removal requests can be sent through the documentation repository. Because the application has no hosted account database, the operator controls the local copies. Never include tokens, passwords, addresses or other private information in a public issue.
