Dododo Local Publisher

A private Windows tool for publishing reviewed videos to the operator's own YouTube channels.

The operator prepares each video, its title, description and thumbnail, then approves a fixed upload list. The program checks which channel is signed in, uploads the selected file privately, sets its thumbnail, and reads the result back from YouTube. Public release or scheduling is a separate step. Returned video IDs are recorded so an interrupted upload is not sent again.

What it sends

Approved video files, thumbnails, titles, descriptions, language settings and publication choices are sent to YouTube through the YouTube Data API. Subtitles are visible inside the video; this tool does not upload separate caption tracks. It does not post comments, subscribe to channels, buy engagement or delete videos.

Access

This is an owner-operated local application, not a public upload service. There is no public account signup and no subscription fee. OAuth authorization is granted through Google. Google passwords, phone verification codes and browser cookies are not collected by the program.

Current status

Initial implementation and local tests are complete. Live verification and YouTube API compliance review are pending. Bulk API publication is disabled until the required approval and real publication checks are complete.
